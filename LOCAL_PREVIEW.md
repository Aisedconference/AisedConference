# Local preview

Start the conference site with:

```sh
cd "/Users/AdamP/Documents/AiSED Conference/conference_site"
npm start
```

Or double-click `start-local.command` on macOS.

Open the seating planner at:

http://localhost:8080/seating.html

The server uses port 8080 so the URL stays stable between sessions. Stop it with `Ctrl+C` in the server window.
